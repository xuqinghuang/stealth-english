# 英语悄悄学 · stealth-english

伪装成工作通知的英语学习悬浮窗。把任意 TXT 切成分句卡片，Edge 神经语音朗读，点单词直接查释义——窗口透明置顶、不进任务栏、鼠标可穿透，屏幕上看起来就是角落的一条工作提醒。

Windows 10 / 11 · 便携版免安装 · Tauri 2 + Rust

## 功能

### 悬浮窗

- 无边框、透明背景、始终置顶，**不出现在任务栏和 Alt+Tab**
- 三种伪装模式：通知卡片 / 纯文字 / 字幕条
- 卡片标题可直接点着改（`contenteditable`，失焦即存），默认「工作提醒」
- 鼠标穿透：空白处不挡底下真正的窗口
- 不透明度 15%–100% 可调
- 字号 11–22 可调
- 字体颜色可调，默认纯白
- 鼠标移开 3 秒后自动变淡
- 位置、尺寸、外观全部记住，下次启动还原

### 练习

- TXT 导入，按句切分，自动识别编码（UTF-8 / GB18030 / UTF-16）
- 自动播放、单句循环、随机顺序，间隔与语速可调
- 中文翻译：悬停显示 / 常显 / 不显示
- 资料库窗口：多本书管理、进度记录、分页练习

### 语音

- Edge 神经语音 **6 个音色**，分 3 类：

  | 类别 | 音色 |
  |---|---|
  | 小女孩 | Ana（美音童声）· Maisie（英音童声） |
  | 女人 | Ava（自然口语，默认）· Aria（清晰朗读腔） |
  | 男人 | Andrew（温暖自然）· Christopher（新闻播报） |

- 合成结果按句缓存（`data/cache/tts/`），同一个句子再播不重新合成
- 合成失败自动回退系统语音，不打断播放；也可全程只用 Windows 内置语音，完全离线

### 查词

- 点句子里的任意单词出词卡：**音标 + 词性 + 中文释义**（刻意不带例句）
- 查过的词缓存在本地（`data/cache/dict.json`），再点秒出，断网也能看
- 失败时只显示失败原因与「重试 / 复制单词」；成功时不显示任何来源或耗时

### 快捷键

默认如下，可在设置里改：

| 快捷键 | 作用 |
|---|---|
| `Alt+H` | 显示 / 隐藏悬浮窗 |
| `Alt+←` / `Alt+→` | 上一句 / 下一句 |
| `Alt+P` | 播放 / 暂停 |

托盘左键 = 显示/隐藏悬浮窗；右键菜单可打开资料库、勾选开机自启、退出。

## 快速开始

解压后双击 `stealth-english.exe`。免安装、免管理员权限。

数据（导入的书、配置、缓存、日志）全部写在 exe 旁边的 `data/` 里，**整个文件夹拷走就能换电脑用**。首次启动会自动生成一本内置示例书。

## 自己构建

前置：Node.js、Rust 工具链（cargo）、Windows WebView2（Win10/11 一般自带）。

```bash
npm install
npm run dev     # 开发运行
npm test        # 逻辑自测（27 项）
npm run pack    # 打包便携版 → dist/stealth-english/
```

`src/` 是页面源码，`web/` 是生成物（`tauri.conf.json` 的 `frontendDist`，编译期嵌入 exe）。**改了 `src/` 不跑 `npm run web`，界面不会变**——`dev` 和 `pack` 都已经自动带上这一步。

## 技术栈

| 层 | 用什么 |
|---|---|
| 外壳 | Tauri 2（Rust），系统 WebView2 渲染，产物约 12 MB |
| 界面 | 原生 HTML / CSS / JavaScript，无框架 |
| 数据 | 本地 JSON，不联网、不装数据库 |
| 打包 | 便携版文件夹，单个 exe |

## 关于外部接口（重要）

语音合成和查词各走了一个外部接口，**两个都不是官方 API**：

| 用途 | 接口 | 性质 |
|---|---|---|
| 语音合成 | 微软 Edge 朗读端点（WebSocket + `Sec-MS-GEC` 鉴权） | 非官方，逆向 |
| 查词 | 有道 `dict.youdao.com/jsonapi` | 非官方，逆向 |

两者都做了完整降级，接口出问题不会让程序崩溃：语音失败静默回退系统语音，查词失败显示失败卡片（并给出「复制单词」出口）。但接口本身没有契约、随时可能变更。

**如果你要分发或商用，请替换成有授权的服务**——语音换 Azure 语音合成，查词换有道 / 百度的开放平台（注意有道官方 API 条款禁止缓存查询结果，而本项目依赖缓存）。
